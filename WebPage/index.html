快速安装指南

三步完成安装，兼容所有版本x64dbg，上手简单高效

1

准备 x64dbg 调试器

下载并安装 x64dbg（32/64位均可，无需特定版本），若已安装可直接跳过此步骤。

点击直接下载（2025-08-19_19-40.zip）
2

安装插件文件

下载 LyScript 插件压缩包，解压后根据调试器位数选择对应文件。

  • 32位调试器：将 x86 文件夹内所有文件拖拽至调试器安装目录的 plugins 文件夹
  • 64位调试器：将 x64 文件夹内所有文件拖拽至调试器安装目录的 plugins 文件夹
点击下载LyScript MCP组件包（2025年12月28日）
3

安装 Python 依赖包

首先需要关闭自身防火墙，接着终端执行以下命令安装（建议同时安装32/64位包）。

# 安装32位调试器依赖
CMD> pip install x32dbg x64dbg asyncio

# 安装FastMCP服务
CMD> pip install fastmcp==2.13.1

# 验证安装成功
CMD> pip list

安装完成！

现在可以启动 x64dbg，通过 Python 脚本调用 LyScript API 进行自动化调试了。
